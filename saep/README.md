# Säp — Aus allem eine App

**Säp** ist der beste App-Programmierer der Welt. Beschreibe deine Idee in natürlicher Sprache — Säp erkennt Features, Struktur und Design und baut daraus eine vollständige App-Vorschau.

## Features

- **Natürliche Sprache** — Beschreibe deine App-Idee, Säp versteht sie
- **Intelligente Erkennung** — Automatische Feature- und Kategorie-Erkennung
- **Live-Vorschau** — Interaktive Phone-Preview mit echten Screens
- **Vorlagen** — Restaurant, Fitness, Shop, Werkstatt, Events, Gesundheit
- **Sofort starten** — Kein Account, keine Wartezeit

## Lokal starten

```bash
cd saep
npm install
npm run dev
```

Dann `http://localhost:3000` öffnen.

## Wie es funktioniert

1. Beschreibe deine App-Idee im Textfeld (oder wähle eine Vorlage)
2. Klicke „App bauen" — Säp analysiert deine Idee
3. Erkannter Name, Features, Screens und Stats werden generiert
4. Interaktive Vorschau im Phone-Frame — zwischen Screens wechseln

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Intelligente Keyword-basierte App-Generierung
